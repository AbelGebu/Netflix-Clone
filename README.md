
# Netflix Clone

A Netflix-inspired landing page built using HTML and CSS. This project recreates the look and feel of the Netflix India homepage for frontend development practice.

## Features

- Netflix-inspired homepage design
- Hero section with email input and call-to-action button
- Trending movies and shows section
- Feature cards highlighting streaming benefits
- Frequently Asked Questions (FAQ) section
- Local image assets
- Responsive page styling

## Technologies Used

- HTML5
- CSS3


## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `Index.html` in your web browser.

Alternatively, use Visual Studio Code with the Live Server extension to run the website locally.

## Project Purpose

This project was created for learning and practicing frontend web development using HTML and CSS.
